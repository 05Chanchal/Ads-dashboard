This project provides a centralized reporting solution for Flipkart Ads and Amazon Ads, enabling businesses to monitor advertising performance across multiple marketplaces from a single dashboard.

Key Features

✅ Real-time advertising performance tracking
✅ Separate dashboards for Flipkart Ads & Amazon Ads
✅ KPI monitoring (Spend, Units Sold, ROI, ACOS, TACOS, TROI)
✅ SKU-level performance analysis
✅ Date, Month, and Product-wise filtering
✅ Interactive charts and drill-down insights
✅ Mobile-friendly and business-focused design
✅ Automated data refresh through Microsoft Fabric

Business Value
Tracks ad spend efficiency and profitability
Identifies top-performing SKUs
Measures advertising ROI and ACOS trends
Supports data-driven marketing decisions
Reduces manual reporting effort through automation
